# Infrastructure Testing

Do not create, change, or run infrastructure tests by default. The `infra/`
directory is the original self-hosted Supabase project and is maintained by the
repository owner for educational purposes.

When asked about its behavior, inspect and explain the existing Supabase and
Docker configuration. Run tests, validation, migrations, resets, updates, or
other operational commands only when the repository owner explicitly requests
that specific action.
