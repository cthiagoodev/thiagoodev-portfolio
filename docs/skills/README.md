# Repository Skills

These guides organize working rules by codebase area.

- [`frontend/`](frontend/) contains frontend architecture, testing, and agent
  boundary guidance.
- [`backend/`](backend/) contains backend architecture, testing, and agent
  boundary guidance.
- [`infrastructure/`](infrastructure/) contains infrastructure architecture,
  testing, and agent boundary guidance.
- [`educator/`](educator/SKILL.md) contains pedagogical guidelines for didactic,
  line-by-line teaching across the entire stack.

Read the repository root [`AGENTS.md`](../../AGENTS.md) first. These guides
provide detailed practices for their respective areas.
