# Thiago.dev Visual Identity

## Concept

thiago.dev should feel like a software engineer's personal computer system.

The interface combines:

- retro computing
- pixel-art games
- hardware interfaces
- engineering workstations
- old operating systems
- cyberpunk
- subtle dark fantasy
- space / cosmic atmosphere

The website must NOT look like a generic developer portfolio.

## Personality

The interface should feel:

- technical
- mysterious
- precise
- engineered
- retro
- slightly experimental
- professional

Professionalism is more important than visual spectacle.

## Core metaphor

The website is a computer system.

Pages and features are modules loaded by that system.

Examples:

HOME       -> SYSTEM / PROFILE
ABOUT      -> IDENTITY MODULE
EXPERIENCE -> CAREER LOG
PROJECTS   -> PROJECT REGISTRY
COMMUNITY  -> NETWORK / COMMUNITY NODE
CONTACT    -> COMMUNICATION TERMINAL

HTMX navigation should reinforce the feeling that modules are being loaded
inside the same running system.

## Avoid

Never default to:

- generic SaaS layouts
- glassmorphism everywhere
- large gradient blobs
- excessive neon
- Matrix rain
- fake hacker terminals
- random binary decoration
- excessive glow
- excessive animations
- huge typography without purpose
- generic portfolio cards

Retro elements must communicate something or reinforce the system metaphor.

## Visual hierarchy

The content is always more important than decoration.

Decorative hardware and system elements should remain secondary.

Use negative space generously.

Do not allow multiple elements to compete for attention.
